# Jobkit Docs

Durable docs for the job-search system live here. Root-level files should stay limited to project
entry points such as `README.md`, `CHANGELOG.md`, `pyproject.toml`, and `justfile`.

## Operational

- [job-boards.md](job-boards.md) — board coverage, refresh behavior, and what is pullable.
- [board-notes.md](board-notes.md) — implementation details for each scraper.
- [ingestion-architecture.md](ingestion-architecture.md) — principles and target design for
  resumable board refreshes.
- [ingestion-research.md](ingestion-research.md) — source-backed research on Python, uv, SQLite,
  Cloudflare, D1, Queues, Workflows, and ingestion prior art.
- [job-search-playbook.md](job-search-playbook.md) — ESL job-search strategy and outreach rules.
