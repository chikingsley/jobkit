# JobKit implementation roadmap

This roadmap contains unfinished work in dependency order. [`PRODUCT.md`](PRODUCT.md) defines the stable product contract, and [`docs/user-flows/`](docs/user-flows/README.md) defines each journey.

Every product slice follows the same sequence: research and contract, implementation, then independent verification. A checkbox closes only after the verification packet includes production-shaped API and database evidence, loading/error/empty/success behavior, URL and Back behavior, keyboard and focus behavior, screenshots at the required phone/iPad/desktop/zoom viewports, and an end-to-end journey.

## 2. Canonical inventory and workspace stabilization

- [ ] `[SHELL-001]` Implement one shared adaptive list-detail shell for Jobs, Campaigns, and Messages. Make selection and query-state changes atomic, preserve Back/Forward and scroll state, expose real loading/error/empty/retry states, and verify phone, iPad, desktop, and 200% zoom layouts.
- [x] `[JOBS-QUERY-001]` Replace the multi-megabyte all-jobs bootstrap with server-side search, filters, sort, pagination, and selected-detail loading. Keep public browse queries and private review filters on their respective route contracts. Affected flows: `FLOW-000`, `FLOW-010`, `FLOW-011`. Known cost: `totalCount` counts rows before match-label filtering, so a page can return short with more remaining (pinned in `jobs-list-pagination` tests).
- [ ] `[CANDIDATE-COORDS-001]` Locality, region, and address locations store `coordinate_kind='provider_point'`, which the candidate schema rejects (`point`/`centroid` only) — locality-scoped listings can never become prepared public candidates, so only countrywide listings publish today. Fix the kind mapping or widen the schema with evidence, then re-run projection for blocked components. Primary suspect for the thin public catalog. Affected flows: `FLOW-000`, `FLOW-011`.
- [ ] `[DRIZZLE-001]` Convert repository SQL to Drizzle with an introspected schema, drizzle-kit migrations going forward, and raw SQL retained only where Drizzle cannot express it (triggers, guarded batches). Owner directive 2026-07-24.
- [ ] `[LOCATION-001]` Add Mapbox-backed canonical job locations with persistent provider identity, coordinates, bounds, resolution evidence, ambiguous/unresolved states, and the accessible map dialog. Backfill and manually verify representative country, city, remote, countrywide, multi-location, and ambiguous records. Affected flows: `FLOW-000`, `FLOW-010`, `FLOW-020`.
- [ ] `[INVENTORY-001]` Prove one complete hosted inventory cycle from UI or scheduled D1 request through the paired runner, Go collector, resumable snapshot publication, D1 reconciliation, and visible source-specific outcome. Affected flow: `FLOW-040`.
- [ ] `[BACKFILL-001]` Complete a source-stratified production canary and full Codex backfill for match facts, position analysis, and normalized listing content. Validate source-hash freshness, evidence preservation, retries, position splitting, canonical entity mapping, and publication eligibility before promotion. Affected flows: `FLOW-000`, `FLOW-010`, `FLOW-011`.
