# Jina embeddings v4

Official model page: <https://jina.ai/models/jina-embeddings-v4/>

## Published model shape

- 3.8 billion parameters
- text, image, and PDF input
- 32,768-token native context
- 2,048-dimensional single-vector output plus a multi-vector mode
- retrieval, text matching, and code task adapters; the separate Classifier API also advertises v4 for universal multimodal classification

## JobKit questions

v4 belongs in both the classifier matrix and the multimodal document and visual-listing retrieval track. The classifier result must be kept separate from the retrieval result because the individual model page and the Classifier API describe different task surfaces.

The useful comparison is whether v4 improves duplicate detection or retrieval for mixed text, screenshots, and PDFs enough to justify its larger model and latency. Text-only results and multimodal results must be reported separately.
