# Jina embeddings v3

Official model page: <https://jina.ai/models/jina-embeddings-v3/>

## Published model shape

- 570 million parameters
- text input
- 8,192-token context
- 1,024-dimensional output with Matryoshka truncation
- retrieval, text matching, separation, and classification task adapters
- current Jina API availability for embedding, zero-shot classification, and hosted few-shot training

## JobKit questions

v3 is the current zero-shot classification baseline because its published task surface explicitly includes classification and it produced the strongest JobKit result. Jina's current model catalog does not mark v3 deprecated. It does recommend newer models generally, so JobKit still compares v3 with v4 and v5 instead of treating one benchmark win as permanent. The experiment measures whether its multilingual classification adapter separates English teaching, subject teaching, non-teaching, and unclear listings without collapsing adjacent classes.

Run both zero-shot and hosted private-classifier experiments. Keep retrieval and deduplication results in the embedding track; those results do not establish classification quality.
