# IPA chart — International Phonetic Association

The official IPA chart ("IPA Kiel", current English edition), downloaded 2026-06-07 from
<https://www.internationalphoneticassociation.org/content/ipa-chart>.

## Files

- `IPA_Kiel_chart.pdf` — the current full chart, 1 page, vector PDF.
- `IPA_Kiel_chart_1200.png` — 10200×13200 raster of the same chart (largest published PNG).
- `IPA_Kiel_chart_0600.png` — 5100×6600 raster (smaller working copy).
