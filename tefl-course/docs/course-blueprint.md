# Course blueprint — 120-hour TEFL certificate, unit by unit

The pre-production master plan (2026-06-07). Every unit named, sourced, and statused. Built from: the full teacherrecord map ([course-structure-reference.md](course-structure-reference.md)), the verified benchmark + gap analysis ([curriculum-research.md](curriculum-research.md)), the State Dept corpus ([SOURCES.md](SOURCES.md)), and the verified citation set. Production method per unit = the pilot process ([../pilot/unit-spec.md](../pilot/unit-spec.md)): source-grounded drafting → anti-slop gate → owner review.

## Status legend

- ✅ **corpus-covered** — a State Dept module or companion chapter carries the unit; restructure like the pilot.
- 🟡 **partial** — corpus or verified citations cover part; the rest is original writing from uncopyrightable facts (grammar rules, standard ELT practice) with owner textbooks as coverage reference.
- 🔴 **needs sourcing** — no corpus; written fresh from facts + citations, or owner finds reference material. These are the units to look at when sourcing books.
- 🎬 — a public-domain State Dept video exists for the topic (embeddable from their YouTube).
- ⭐ — carries verified research citations (curriculum-research.md §4); these units are the differentiators no budget competitor has.

## The course: 14 modules, 63 units, ~120 hours

Unit = ~1,800–3,000 words of reading + 2–3 inline comprehension checks + 6-question anchored quiz. Module ends with a test that re-asks 2 questions from earlier modules (spaced retrieval, practicing what §M5 teaches). ~2 study-hours per unit + module tests + final ≈ 120 hours. Target text volume ~170–210k words (teacherrecord claims 120hr at ~210k).

## Totals

63 units (the header originally miscounted 57; the module tables below were always right): **17 ✅ corpus-covered · 25 🟡 partial · 15 🔴 needs sourcing** · 12 units ⭐ carry verified citations · ~17 topics have free public-domain video.

## What the owner can source (maps to the 🔴 rows)

1. **Grammar reference** (M2, M3 — 11 of the 15 🔴 units): any standard pedagogical grammar you own works as a coverage/accuracy reference (e.g. the usual suspects: Swan's Practical English Usage, Murphy's English Grammar in Use, Parrott's Grammar for English Language Teachers). Rules are facts; we write our own prose, examples, and exercises.
2. **Business English / one-to-one** (14.2): any business-English coursebook as a topics reference.
3. **Pronunciation** (M6): a phonology reference if you have one; otherwise facts + IPA chart suffice.
4. **CEFR descriptors** (1.4): the Council of Europe publishes the framework — needs a license check on quoting descriptors verbatim vs paraphrasing (flagged, not yet researched).
5. **More State Dept corpus** (free, I can fetch): *Activate: Games for Learning American English*, *Create to Communicate*, *Dialogs for Everyday Use* — activity/example banks for M10/M14.

## Format decisions locked (research-backed)

- Inline checks after each major section + anchored end-of-unit quiz: retrieval practice (Karpicke & Roediger, 2008).
- Module tests re-ask 2 questions from earlier modules: spaced review (Kim & Webb, 2022).
- Embed the public-domain State Dept video where one exists (🎬); AI-avatar videos for the rest are a later, separate workstream (HeyGem/LivePortrait research pending).
- Mayer's multimedia principles: cited-design candidate, NOT yet verified — run through citation verification before designing video segments around it.

## Production order (when approved)

1. **Wave 1 — ✅ units (17)**: pure pilot-process restructuring; fastest, proves volume.
2. **Wave 2 — 🟡 units (25)**: corpus + original writing; owner textbooks useful as reference here.
3. **Wave 3 — 🔴 units (15)**: after owner sourcing; grammar modules benefit most from a reference at hand.
4. Module tests + final exam + course intro last, once unit content is stable.
